# 💬 Testimonials Photos

Drop recommender and executive headshots in this folder.

### Tips:
- Recommended format: Square JPG or PNG (e.g. 300x300px or 400x400px).
- In the Google Sheet under the **`Testimonials`** tab, you can enter the filename in a `PhotoURL` column (e.g. `trinayan_saikia.jpeg` or `images/testimonials/trinayan_saikia.jpeg`).
- If no photo is provided for a person, the system automatically generates a stylish 2-letter monogram avatar (e.g., `TJS`) with terracotta styling.
